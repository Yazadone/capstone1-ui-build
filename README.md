# meFST - HTML/CSS/JavaScript UI Demo

This folder contains a simple class demo UI for meFST.

It uses:

- HTML
- CSS
- JavaScript

## How to run

Right-click the file `index.html` and choose your prefered browser.

## Pages

- `index.html` - Sign In page
- `register.html` - Request Access form
- `home.html` - Home / landing page
- `datasets.html` - Dataset Discovery page
- `dataset-detail.html` - Dataset details page
- `saved.html` - Saved Datasets page
- `documentation.html` - Documentation page
- `access-requests.html` - Access Requests page
- `analyses.html` - Analyses page
- `exports.html` - Export History page
- `admin.html` - Admin Dashboard page

## Other files

- `styles.css` - all styling
- `data.js` - mock data for datasets, users, requests, analyses, exports
- `app.js` - button clicks, search, filters, save button, modal, admin tabs
