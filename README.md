# meFST - popArrayDB HTML/CSS/JavaScript UI Demo

This folder contains a simple class demo UI for popArrayDB.

It uses:

- HTML
- CSS
- JavaScript
- Mock data only
- No API
- No database
- No React
- No npm

## How to run

Open this file in your browser:

```text
index.html
```

You can also right-click `index.html` and choose **Open with Chrome**.

## Pages

- `index.html` - Sign In page
- `register.html` - Request Access form
- `home.html` - Home / landing page
- `datasets.html` - Dataset Discovery page
- `dataset-detail.html` - Dataset details page
- `saved.html` - Saved Datasets page
- `documentation.html` - Documentation page
- `access-requests.html` - Access Requests page
- `analyses.html` - Analyses page
- `exports.html` - Export History page
- `admin.html` - Admin Dashboard page

## Other files

- `styles.css` - all styling
- `data.js` - mock data for datasets, users, requests, analyses, exports
- `app.js` - button clicks, search, filters, save button, modal, admin tabs

## Demo notes

The buttons are clickable and show demo actions. Nothing is connected to a real API or database.
Saved datasets use browser localStorage, so saved items stay on your computer until the browser storage is cleared.
